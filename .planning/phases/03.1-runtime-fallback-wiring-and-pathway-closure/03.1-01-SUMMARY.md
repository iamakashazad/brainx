**Shared analyze jobs now choose text or slideshow-video inference at runtime and still emit per-screen activation manifests with explicit pathway metadata**

## Accomplishments
- Added deterministic runtime helpers to decide whether content is eligible for slideshow fallback and whether `/analyze` should run `text` or `video`.
- Added upload-path resolution, simulation-timeline duration derivation, and contiguous activation splitting so one video inference result can be rejoined to the existing per-screen pipeline contract.
- Wired `backend/core/queue.py` to build `activations/{job_id}/fallback_slideshow.mp4`, run `run_tribev2_video()` for eligible visual jobs, and persist pathway metadata in `AnalysisResult`.
- Preserved text-only analyze behavior and the legacy `/test-inference` inference-only branch.

## Files Created/Modified
- `backend/services/pathway_config.py` - Resolves content eligibility and the runtime analyze pathway from the Phase 1 default.
- `backend/services/video_slideshow.py` - Resolves uploaded image files, derives deterministic slideshow durations, and splits video activations back into contiguous per-screen slices.
- `backend/models/results.py` - Adds additive `pathway` metadata to the stable schema-version-1 result envelope.
- `backend/core/queue.py` - Selects text vs video inference at runtime, builds slideshow artifacts, writes per-screen activation slices, and persists pathway metadata.
- `tests/test_runtime_fallback.py` - Covers the helper-layer contract for pathway selection, duration derivation, activation slicing, and result metadata.
- `tests/test_analyze.py` - Proves text jobs stay on the text branch, visual jobs can use video fallback, short video activations fail closed, and legacy `/test-inference` remains isolated.
- `tests/test_result_schema.py` - Updates the schema round-trip fixture to include the new additive `pathway` field.

## Decisions Made

- Kept `DEFAULT_PATHWAY` as the only shipped selector for the fallback decision and avoided any request-schema or database changes.
- Stored slideshow artifact paths as workspace-relative strings (`activations/{job_id}/...`) instead of absolute paths to satisfy the result-envelope threat model.
- Reused the existing per-screen activation manifest contract for both text and video analyze jobs so ROI aggregation, continuity, and recommendations required no downstream API changes.
