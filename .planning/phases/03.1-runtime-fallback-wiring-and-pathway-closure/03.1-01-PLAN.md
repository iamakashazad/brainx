## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted content metadata -> queue worker | Uploaded visual content metadata crosses from database records into runtime slideshow assembly |
| local screen files -> moviepy slideshow build | The worker reads on-disk user-provided images and turns them into an MP4 artifact |
| video activation timeline -> per-screen slices | A single model output is partitioned into screen-specific arrays before downstream scoring |
