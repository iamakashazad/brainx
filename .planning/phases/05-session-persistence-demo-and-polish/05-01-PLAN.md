
Add the endpoint exactly as:
```python
@router.get("/jobs", response_model=list[JobSummary])
async def list_jobs() -> list[JobSummary]:
    async with database.async_session() as session:
        result = await session.execute(
            select(Job)
            .where(Job.persona_id.isnot(None))
            .where(Job.content_id.isnot(None))
            .order_by(Job.created_at.desc())
            .limit(50)
        )
        jobs = result.scalars().all()
    return [
        JobSummary(
            job_id=j.id,
            status=j.status,
            persona_id=j.persona_id,
            created_at=j.created_at.isoformat() if j.created_at else None,
        )
        for j in jobs
    ]
```

Filter rationale (Pitfall 3 from RESEARCH.md): legacy `/test-inference` jobs have null `persona_id`/`content_id` and would render as broken cards. The two `.where()` clauses exclude them.

Ordering: descending `created_at` so newest sessions appear first. `.limit(50)` caps the response at 50 entries (single-user MVP — no pagination cursor needed).

Do NOT add a `/jobs/{job_id}` join with persona — frontend resolves persona names from its existing `usePersonasQuery` cache (Open Question 1 in RESEARCH.md, recommendation: A1).
