## Color

All values reference `var(--*)` tokens from `frontend/src/styles/tokens.css`. No color literals permitted in Phase 5 components (Phase 4 D-19 locked).

Dark theme is the default. Light theme is activated by the new theme toggle (Phase 5 D-11) — tokens already exist in `:root` (light) and `.dark` (dark) palettes.

| Role | Token | Dark Value | Light Value | Usage |
|------|-------|-----------|-------------|-------|
| Dominant (60%) | var(--background) | oklch(0.21 0.02 226.02) | oklch(0.96 0.01 196.81) | Page background, history screen canvas |
| Secondary (30%) | var(--card) | oklch(0.23 0.03 218.18) | oklch(0.98 0.00 196.66) | Session history cards, demo card base, modal/overlay surface |
| Accent (10%) | var(--primary) | oklch(0.72 0.12 210.36) | oklch(0.72 0.12 210.36) | See reserved list below |
| Destructive | var(--destructive) | oklch(0.64 0.21 25.39) | oklch(0.64 0.21 25.39) | Delete session confirmation dialog only |

**Accent (var(--primary)) reserved for:**
1. "New Analysis" CTA button background
2. Active/hover state on the theme toggle icon
3. Status badge for "DONE" / completed sessions (using `var(--primary)` as badge fill or `bg-primary/10 text-primary` pill)
4. Demo card's distinct border color (`border-primary`) — signals it is the featured starting point

**Second semantic color reserved for:**
- `var(--destructive)` — used only on the delete-session confirmation dialog (if implemented). Not used on queue-busy 503 error (that uses muted/card styling).
- `var(--muted-foreground)` — for "RUNNING", "PENDING" status badges (subdued, non-prominent)

**Demo card visual distinction (Claude's Discretion — D-05):**
- Border: `border-2 border-primary` (2px solid accent border, not 1px default)
- Badge: "DEMO" label in `bg-primary/10 text-primary` pill, positioned top-right of card
- Pinned position: always renders as first item in the grid; a small pin icon (`lucide-react Pin`) is shown at top-left of the card

Source: tokens.css verified; Phase 4 D-19 (no color literals); Phase 4 D-20 (dark default); CONTEXT.md D-05 (demo card distinct).

## Interaction Contract

### Session Card Interactions

| Interaction | Behavior |
|-------------|----------|
| Hover | `hover:shadow-xl` lift (same as PersonaCard pattern) + slight `scale(1.01)` via framer-motion |
| Click (completed session) | Sets `wizardStore.setJob(jobId)` + `setStep(4)`, opens WizardShell overlay at Results |
| Click (demo card) | Fetches `/demo/result.json`, injects into ResultsLayout via `resultOverride` prop; no job ID written to wizardStore |
| Click (failed session) | Opens result view showing FailureState with the stored `error_message` |

### Theme Toggle Interactions

| Interaction | Behavior |
|-------------|----------|
| Click | Toggles `themeStore.theme` between "dark" and "light"; applies/removes `.dark` class on `document.documentElement`; persists to `localStorage` key `brainx-theme` |
| Page load | Inline `<script>` in `index.html` reads `localStorage["brainx-theme"]` and applies `.dark` class before first paint (prevents FOUC) |
| Icon display | Sun icon when dark theme active (clicking = switch to light); Moon icon when light theme active (clicking = switch to dark) |

### Queue-Busy 503 Interaction

| Trigger | Behavior |
|---------|----------|
| POST /analyze returns 503 | `useSubmitAnalyze.onError` intercepts; does NOT open wizard progress view; renders inline error message below the "Analyze" button in the wizard content step |

### Shareable URL (`/results/:jobId`)

- No special interaction beyond page load: `SharedResultsPage` fetches `GET /jobs/:jobId`, renders `ResultsLayout`. On fetch error (job not found), renders a centered error card with "Session not found" copy and a "Go to History" link.

## Motion Contract

Phase 5 maintains the "rich/cinematic" motion established in Phase 4 (D-23), applied with restraint on new components.

| Element | Motion |
|---------|--------|
| History card hover | `scale(1.01)` + shadow lift via framer-motion, 150ms ease-out |
| History grid mount | Cards stagger-fade in: 60ms delay per card, `opacity: 0→1` + `y: 8→0`, 200ms ease-out |
| WizardShell overlay open | Existing animation (no change) |
| Theme toggle icon swap | 200ms cross-fade between Sun and Moon icons |
| Empty state | Subtle `opacity: 0→1` + `y: 12→0` on mount, 300ms ease-out |

No new motion libraries required — framer-motion v12.38.0 already installed.
